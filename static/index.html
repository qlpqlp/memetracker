How MemeTracker works

          
MemeTracker connects to the Dogecoin P2P network, requests the mempool, and listens for transaction inventory and raw transactions. It does not sync the blockchain. When a transaction pays one of your tracked P2PKH-style outputs, the app records txid, time, and DOGE amount and stores it under your data directory.

          
Dashboard

          
Summary counters plus live trend charts (mempool visibility, connected workers, stored rows and tracked addresses) built from browser polling while you keep the dashboard open.

          
Start / Stop

          
Start writes memetracker_config.json and launches workers. Stop signals workers to exit between connections (an active peer session may take a short while). A complete config file on disk can auto-start P2P when the process launches.

          
Configuration

          
Adjusts retention and per-address tx cap in settings.json without restarting P2P.

          
Track address

          
Same as GET|POST /track/{address}. Keeps the address watched and bumps retention.

          
Tracked addresses / Transactions

          
On-disk mirror of what you are watching and what was detected. Removing an address deletes its file and tx history in the app.

          
API access

          
Optional IP allowlist for JSON/track endpoints (see section above).

        

        

          
HTTP API reference

          
Replace BASE with your server origin, e.g. http://127.0.0.1:33555.

          
Status & health

          
curl -s BASE/api/status
curl -s BASE/healthz

          
Start / Stop P2P

          
curl -s -X POST BASE/api/start -H "Content-Type: application/json" -d "{\"http_port\":33555,\"http_bind\":\"0.0.0.0\",\"network\":\"mainnet\",\"storage_dir\":\"\",\"list_limit\":10,\"retention_days\":7,\"p2p_host\":\"\",\"p2p_port\":22556,\"p2p_parallel\":3,\"p2p_log\":1}"

curl -s -X POST BASE/api/stop

          
Runtime limits

          
curl -s -X POST BASE/api/config -H "Content-Type: application/json" -d "{\"list_limit\":20,\"retention_days\":14}"

          
API allowlist

          
curl -s -X POST BASE/api/allowlist -H "Content-Type: application/json" -d "{\"api_allowed_ips\":[\"127.0.0.1\",\"10.0.0.0/24\"]}"

          
Track address

          
curl -s "BASE/track/YourP2PKHAddress"

          
Remove address / tx row

          
curl -s -X DELETE "BASE/api/addresses/{hash160_hex}"
curl -s -X DELETE "BASE/api/transactions?txid=...&hash160_hex=..."

          
All API responses are JSON unless noted. Errors include an error string. A complete memetracker_config.json shape is required for /api/start; you may include api_allowed_ips as an array of strings.
